StreamHouse for Inventory Management

Retail events stream into Kafka. Flink SQL forecasts demand by product, region, and channel, then compares that forecast with inventory to flag stockout and overstock risk. The source for this demo lives in this folder.

GitHub Pages serves the files. The live dashboard needs the local Python app, because it reads a stream from the API.

Run it locally

cd demos/streamhouse-inventory
make dashboard-offline

That opens the dashboard at http://localhost:8000 without Confluent Cloud. The full pipeline is in the README.
